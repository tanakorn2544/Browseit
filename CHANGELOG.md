# Changelog

All notable changes to **BrowseIt** will be documented in this file.

## [1.0.1] — 2026-04-04

### Added

- **Add to Pie from Search** — After searching with `Alt + Shift + Q`, a dialog now pops up letting you assign the selected tab directly to a pie menu slot

---

## [1.0.0] — 2026-04-04

### Added

- **Favorites Pie Menu** — Press `Alt + Q` to open an 8-slot pie menu for quick tab access
- **Search All Tabs** — Press `Alt + Shift + Q` to search through every N-Panel tab
- **Add to Pie from Search** — After searching, a dialog lets you assign the tab to a pie slot
- **Configurable Slots** — Assign any N-Panel tab to 8 directional slots via addon preferences
- **Auto-detection** — Automatically discovers all N-Panel categories from installed addons
